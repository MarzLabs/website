Productos

Marz Labs construye y opera software empresarial para el mercado centroamericano. Cada producto está diseñado para resolver un problema concreto del entorno empresarial regional.

  • Fiscaliza.me

    Plataforma de facturación electrónica, punto de venta y gestión empresarial para pequeñas y medianas empresas en El Salvador. Disponible como aplicación web y como aplicación móvil para Android.

    Conocer Fiscaliza.me

  • Cuadra

    Aplicación de escritorio para contadores de El Salvador que trabajan con Documentos Tributarios Electrónicos (DTE). Descarga del correo los JSON y PDF de cada empresa, los ordena, consulta su estado en Hacienda y prepara los libros y los anexos de la declaración de IVA (F07). Disponible para Windows y macOS.
